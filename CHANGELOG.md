# Changelog

## [0.8.3] — 2026-11-09

- Компактные нижние кнопки каталога: иконка и подпись в одну строку.
- Карточки каталога с книжной миниатюрой, жанром, языком, размером и числом скачиваний при наличии данных.
- Кнопка скачивания прямо на карточке книги при наличии прямой EPUB/TXT-ссылки.
- Подробности книги: аннотация, жанры, издательство, дата и идентификатор издания.
- Сортировка загруженных книг по числу скачиваний; каталоги без счётчика сохраняют исходный порядок.

## [0.8.2] — 2026-11-09

- Закреплённая шапка библиотеки и каталога при прокрутке.
- Отдельная нижняя панель действий и единый стиль переключателя каталога/загрузок.
- Проверки закреплённой шапки, крупных шрифтов и коротких окон; исправлена выгрузка скриншотов тестов.

## [0.8.1] — 2026-11-09

- Публичный репозиторий с инструкциями для AI-агентов и картой архитектуры.
- GitHub Actions: build, lint, проверки текста и Android-тесты с отчётами и скриншотами.
- Автоматические подписанные APK и GitHub Releases по тегам версий.
- Единый файл версии, проверка сертификата, checksum APK и Gradle Wrapper.
- Подробная документация и свежие снимки интерфейса на оригинальных демоисториях.

## [0.8.0] — 2026-11-08

- Адаптивная сетка библиотеки и две колонки каталога для широких окон.
- Сохранение чтения и каталога при раскрытии/складывании, включая малые изменения окна.
- Общие press/hover/focus/disabled состояния, улучшения крупных шрифтов и коротких окон.
- Обновление прогресса загрузки без постоянного пересоздания карточек.
- Добавление и удаление HTTPS-зеркал после проверки OPDS.

## [0.7.0] — 2026-11-08

- Флибуста/OPDS и прямые загрузки EPUB/TXT вместо торрент-клиента.
- Автоматическая подгрузка результатов, ограниченные ретраи и переключение зеркал.
- Упрощённые поиск и навигация каталога, фоновый импорт в библиотеку.

## [0.6.0 and earlier]

- Нативная библиотека, EPUB/TXT, обложки и оглавление, поиск и закладки.
- RSVP для русского и английского, темы и настройки для каждой книги.
- Отдельный экран настроек, собственные диалоги и оптимизация длинных книг.
- Торрент-прототип был удалён в 0.7.0 и больше не входит в приложение.
